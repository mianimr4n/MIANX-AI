    12→    12→
    13→    13→# 1. Purpose
    14→    14→
    15→    15→Mianx.ai must be commercially capable before individual Domain OS
    16→    16→products scale.
    17→    17→
    18→    18→The billing platform therefore belongs to **Mianx.ai Core**.
    19→    19→
    20→    20→``` text
    21→    21→Customer
    22→    22→   ↓
    23→    23→Organization
    24→    24→   ↓
    25→    25→Subscription
    26→    26→   ↓
    27→    27→Plan
    28→    28→   ↓
    29→    29→Entitlements
    30→    30→   ↓
    31→    31→Domains / Modules / Features
    32→    32→   ↓
    33→    33→Usage
    34→    34→   ↓
    35→    35→Billing
    36→    36→```
    37→    37→
    38→    38→The goal is to make every domain commercially configurable without
    39→    39→creating a separate billing system.
    40→    40→
    41→    41→------------------------------------------------------------------------
    42→    42→
    43→    43→# 2. Commercial Constitution
    44→    44→
    45→    45→1.  Billing is a Core platform capability.
    46→    46→2.  Subscription status determines commercial access.
    47→    47→3.  Authorization still determines security access.
    48→    48→4.  Entitlement determines whether a capability is commercially enabled.
    49→    49→5.  Feature flags are not billing.
    50→    50→6.  Usage metering must be independent from UI display.
    51→    51→7.  AI usage and AI cost must be measurable.
    52→    52→8.  Domain products must be packageable independently or together.
    53→    53→9.  Upgrade/downgrade must preserve data safely.
    54→    54→10. Billing failures must have controlled grace and suspension behavior.
    55→    55→
    56→    56→------------------------------------------------------------------------

   187→   187→# 8. Entitlements
   188→   188→
   189→   189→Entitlements answer:
   190→   190→
   191→   191→> Is this organization commercially allowed to use this capability?
   192→   192→
   193→   193→Possible states:
   194→   194→
   195→   195→``` text
   196→   196→enabled
   197→   197→disabled
   198→   198→limited
   199→   199→trial
   200→   200→expired
   201→   201→suspended
   202→   202→```
   203→   203→
   204→   204→Authorization answers whether the user may use it.
   205→   205→
   206→   206→Entitlement answers whether the organization has purchased it.
   207→   207→
   208→   208→Both checks may be required.
   209→   209→
